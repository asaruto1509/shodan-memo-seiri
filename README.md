# 商談メモ整理テンプレート

商談後のメモを「相手の課題・提案の方向・確認事項・次の行動」に整理し、提案書の骨子へつなげる日本語テンプレートです。

専任の営業企画がいない小規模BtoB事業者の代表・営業担当を想定しています。Markdownファイルなので、テキストエディタ、社内Wiki、各種AIチャットへ貼り付けて使えます。

## すぐ使う

- [ブラウザ版の商談メモ整理シート](https://shodan-memo-seiri.raitoninngu11111.chatgpt.site/?utm_source=github&utm_medium=referral&utm_campaign=shodan_memo_template)
- [テンプレートを開く](templates/shodan-memo-template.md)
- [詳しい無料解説を読む](https://tips.jp/u/ai-lab/a/o6yQ2Vvb?utm_source=github&utm_medium=referral&utm_campaign=shodan_memo_template)

ブラウザ版は登録不要です。入力内容はブラウザ内だけで処理され、サーバーへ保存・送信されません。

## 使い方

1. `templates/shodan-memo-template.md`を開き、右上のダウンロードボタンから保存するか、内容をコピーします。
2. 氏名、メールアドレス、電話番号など、整理に不要な個人情報を削除します。
3. 商談メモを4つの欄へ振り分けます。
4. 「提案書の骨子」を埋め、担当者と期限を確認します。

## 向いている場面

- 商談メモが記録だけで止まり、提案書へ進めない
- 担当者ごとにメモのまとめ方が違う
- 課題と提案内容が混ざっている
- 次回までの担当者と期限が曖昧になる

## ファイル構成

- `templates/shodan-memo-template.md`: 記入用テンプレート
- `docs/`: GitHub Pages版の案内ページ
- `.github/workflows/link-health.yml`: 公開リンクの週次確認
